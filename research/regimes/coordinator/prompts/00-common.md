# r1 regime expedition: instructions common to every worker

You are one of five workers in a CPU-scale exploratory expedition in `bfaber-centaur/modest-complexity`, requested by Bobby. The coordinator is the project thread "Four-regime expedition". Your role file (01–05 in this folder) says which part is yours.

## Before anything else

1. Fetch and merge `origin/swarm/regimes` into your designated branch. Your base is the commit named in your launch text. A later `swarm/regimes` commit is equally valid if it changes nothing in `research/regimes/common/`.
2. Read these, in this order:
   - [../../PLAN.md](../../PLAN.md): branches, directories, seeds, shared code, environment, budgets, milestones M0–M4, figure standard, communication;
   - your role file;
   - `AGENTS.md`;
   - the figure section of `research/RED_TEAM.md`.
   The e1–e4 material under `research/` is about modular addition. Read it only if you want examples of conventions.
3. Install uv 0.12.23 as in PLAN §3. Run the shared tests.

## Hard rules

- Write only inside your own directory. Never push to `swarm/exploration`, `swarm/regimes`, either `main`, or upstream. Never edit `research/regimes/common/`, top-level files, or another lane's directory. PRs target `swarm/regimes`.
- Leave the e4 round (on `swarm/exploration`, three other threads) alone.
- Every numerical run goes through `research/regimes/common/run_jobs.py` from a plan entry pushed before launch, with `--workers` ≤ 2. Keep failed and capped runs. Never reuse a run ID or overwrite an output directory.
- Stay within your budget (PLAN §4). If you will exceed it, stop and ask the coordinator.
- Keep code small: a task/oracle module, a training script and a figure/analysis script, or fewer. Reuse `common/nets.py` where it fits. No frameworks, no new dependencies, no large autogenerated reports.
- Do not simulate or pre-write results. Every number in a note comes from a committed artifact, with its run ID.
- Use reasoning heavily: for predictions, controls, implementation review and counterexamples. Inference is abundant; CPU time, Bobby's attention and integration capacity are not.

## What "done" looks like for an investigator

`research/regimes/<lane>/` contains:
- `QUESTION.md` (M0, with a later "Follow-up" section);
- `NOTE.md`: question, design, observations, limitations, next question, in about a page;
- `README.md`: exact commands, environment, budget tally, run manifest summary;
- `plan.json` and `registry.jsonl`;
- the code;
- `figures/` holding the primary figure as PNG + SVG + CSV, plus any supporting ones;
- `runs/` holding the published small run files with a SHA-256 manifest.

The primary figure is the first-figure spec from your role file, unless the data show a better one. If so, say why in NOTE.md.
