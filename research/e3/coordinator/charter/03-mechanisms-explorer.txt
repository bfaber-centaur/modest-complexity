Question
After the frequency filter improves a failed model, does subsequent training preserve, strengthen, or erase that improvement?

Initial experiment
Use the same three failed 30%-setting width-128 checkpoints at 50k updates from e1/e2. For each checkpoint create:
A. Unchanged weights.
B. The existing per-unit dominant-frequency filter.
C. A sham using non-dominant frequencies.

Resume all nine branches for 20k updates on the original training set and original objective. Reset Adam moments AND optimizer step count in every branch, including A. Record original checkpoint age separately from continuation updates. This studies recovery after a common optimizer reset, not uninterrupted training.

Intervention controls
Reuse the existing filter exactly and document it. Choose sham frequencies using recorded random seeds, without held-out performance selection. Match perturbation size as closely as practical using a declared label-free rule; report actual parameter displacement and logit change. A sham may differ in retained energy, gate changes, or immediate training damage: measure those differences and do not call it fully matched if it is not.

Do not tune interventions against held-out accuracy. If matching cannot be made meaningful, ask the coordinator to settle the comparison before launching.
