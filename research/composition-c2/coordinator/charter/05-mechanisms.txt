ROLE: MECHANISMS INVESTIGATOR
Question: does the learned hidden state function as a reusable state for subsequent operations, or retain history/position dependence that matters?

Use recovered checkpoints first: tied/inter, untied/inter and tied/final at 10k, three seeds; analyze selected earlier/later snapshots only when available without duplicating training. Begin with ordinary held-out evaluations verified against the oracle.

Primary intervention: natural whole-hidden-state interchange at a step boundary. Run base and donor prefixes, replace the base hidden state with the donor's actual hidden state, retain the base suffix, and continue through the original network. The counterfactual target is the oracle suffix applied to the donor's semantic state. Predeclare pair selection using task structure; report all pairs and a separate subset with correct unpatched base/donor predictions. Include self-swap, same-semantic-state/different-history donors, different-state donors and appropriate random/magnitude-matched controls. Avoid interpreting whole-state replacement as identifying a unique circuit.

Same-step swaps are a useful consistency check, but in a deterministic RNN they are literally evaluation on recombined prefixes/suffixes. Show this equivalence and do not double-count it as independent causal evidence. The stronger test is cross-position interchange: use donor states from another depth, apply a common suffix, and test semantic-state consistency. Specify which per-step transition/readout is used in untied models; cross-position tests there are an explicit distribution shift, not a fair default expectation of invariance.

First figure: suffix-success matrices by donor depth, recipient depth and model condition, with same-state history variation. Fit any probes/maps ONLY on designated training states and evaluate on held-out histories; label position-aligned decoding as descriptive. Do not optimize a subspace on the test counterfactuals.

One adaptive follow-up can test a candidate state subspace with held-out interchange and matched ablations, or trace when cross-position consistency emerges. Nonzero intervention effects require controls for generic disruption; a negative linear-subspace result cannot rule out nonlinear or redundant codes.

Report exactly what is supported: reusable semantic state under specified interventions, history-dependent computation, or unresolved. Strong length-3 accuracy alone does not settle this question.
