ROLE: LEARNED-CORRECTION INVESTIGATOR
Question: can a small correction using only the model's hidden state recover part of the oracle-centroid improvement on unseen programs?

Motivation to verify against final c2 review: replacing depth-two hidden states with training-derived means grouped by the true intermediate symbol improved the weaker RNNs. That intervention supplied an oracle symbol. We now ask whether a learned map can select a useful correction without that symbol at inference.

Main setting: frozen 10k tied-transition RNNs from the original final-only and separate-readout/intermediate arms, three seeds each. Use the original task/split. Freeze every original parameter; hash before/after. Apply one correction at depth two and then the unchanged third transition/readout. Start with a small nonnegative-output bottleneck map, with exact dimensions and optimizer fixed after a training-only calibration. Use the same map architecture/initial draw/update exposure for learned-correction and reconstruction arms. Do not train its targets through the final-answer loss in the main experiment.

Arms:
A. Identity/no correction.
B. Hidden state -> training-derived centroid for its intermediate symbol, trained by squared error. At evaluation input is ONLY h2; no true symbol, raw program, suffix or final answer may enter the correction module.
C. Same architecture trained to reconstruct h2. This controls the module and training, but is not a perfectly matched target-complexity control; report that limitation.
D. Direct symbol decoder from h2, then select that predicted symbol's training centroid and run the unchanged suffix. Train decoder only on allowed training labels. This exposes how much B is effectively a decoder plus re-encoder.
E. True-symbol centroid replacement, labeled oracle reference (not a guaranteed upper bound).

Define centroids from training states only, before evaluation. Weight unique prefixes explicitly rather than accidentally overweighting repeated appearances with different suffixes. Report final accuracy and symbol-decoding/centroid error separately. A correct decoder plus a correctly functioning suffix may explain the entire improvement; that is still useful, but not spontaneous discovery by the frozen model.

CRITICAL OVERLAP CHECK:
In the original split every held-out (start, op1, op2) prefix occurs in training. Because the RNN is causal, its h2 is identical across suffixes. The main result therefore tests novel suffix combinations of seen states, NOT generalization of the correction to unseen hidden states. State this prominently.
Add a grouped-prefix split for the correction's own training/validation/evaluation if feasible within the initial budget: group identical prefixes together, balance symbol coverage using training labels, fit centroids and correction only on the fit groups, and evaluate on excluded prefixes. The frozen base has still encountered those prefixes; label this as adapter-held-out prefixes, not globally unseen prefixes. Do not quietly change the base-network training split.

First figure: original and corrected final accuracy by arm, separate seen-prefix/new-suffix and adapter-held-out-prefix evaluations, with every seed and train performance. Include oracle reference and direct-decoder baseline.

Interpretation: improvement shows a supervised post-hoc correction can use the frozen representation under the specified exposure. It does not show that the base model internally selects centroids, that the history residual is uniformly harmful, or that no new computation was learned by the correction.

One follow-up after the initial figure: test the fixed correction at another depth/longer continuation, or on a second reviewed task draw. Predeclare the application rule; do not repeatedly retune using longer-length answers. Failure there bounds portability rather than invalidating the original improvement.
