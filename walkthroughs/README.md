# Walkthroughs

Small executable reconstructions of findings from the exploratory research. Each
starts with a question, invites a prediction, and separates the observed result
from its interpretation. These are learning artifacts, not new confirmatory runs.

1. [Same computation, different measured complexity](01-rescaling/rescaling.ipynb):
   one ReLU, a real modular-addition checkpoint, and a function-preserving
   transformation that changes the original codec estimate.

See the [setup and reproduction instructions](01-rescaling/README.md).
